# Publicar en el blog de enjoy

1. Crea un archivo `.txt` en esta carpeta. Usa un nombre corto, en minúsculas, con guiones entre palabras.
2. Escribe el artículo como texto, con una línea vacía entre párrafos. Para un subtítulo, inicia el bloque con `## `.
3. Añade una entrada a `index.json` con las mismas claves que las demás. Escribe en `slug` el nombre del archivo sin la extensión y usa el formato `AAAA-MM-DD` para la fecha.
4. Incluye los dos archivos en el mismo cambio y publica en `main`. El sitio mostrará las entradas más recientes primero. Para retirar un artículo del listado, quita su entrada de `index.json`.

El repositorio es público. Publica novedades y guías que puedan leerse fuera de enjoy.
